# TextUtils

TextUtils is a simple React-based text utility application that helps users perform different operations on their text.

## Live Demo

https://abdulrehman3104.github.io/TextUtlilty-Home/

## Features

- Convert text to Uppercase
- Convert text to Lowercase
- Clear text
- Copy text
- Remove extra spaces
- Count words
- Count characters
- Preview text summary
- Extract email addresses from text
- Dark Mode
- Blue Mode
- Yellow Mode
- Light Mode
- Responsive Navbar

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Bootstrap
